# recicla-tech
Este projeto visa treinar e solidificar conhecimentos em desenvolvimento front-end. O foco principal foi a utilização de SASS (SCSS) para aplicar uma arquitetura de estilos moderna e organizada, dividida em parciais (variáveis, componentes, seções, etc.), simulando um ambiente de desenvolvimento profissional.

O desafio foi construir uma landing page responsiva e fiel ao design proposto.

Confira o resultado online: https://recicla-tech-hwlq.vercel.app/
